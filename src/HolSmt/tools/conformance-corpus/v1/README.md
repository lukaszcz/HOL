# HolSmt Conformance Corpus v1

This directory is the versioned SMT-LIB 2.7 corpus for Core, UF, Ints,
Reals, Reals_Ints, ArraysEx, FixedSizeBitVectors, FloatingPoint,
UnicodeStrings/regex, datatypes, and explicitly classified Z3 Seq/Set/Bag
extension conformance evidence.

The corpus is generated by:

```sh
python3 src/HolSmt/tools/conformance-corpus/v1/generate_core_uf_arithmetic_corpus.py
```

`manifest.json` is the stable metadata entry point.  Each case has:

- `id`: stable evidence ID used by conformance reports and coverage manifests;
- `logic`: expected `set-logic`;
- `file`: SMT-LIB script path relative to this directory;
- `tags`: theory family, result class, and audit labels;
- `modes`: conformance runner modes that are applicable to the script;
- `expected`: exact expected failures for diagnostic cases.

The Core/UF/arithmetic cases are generated.  Arrays, bit-vectors, advanced
theories, and Z3 extension cases are hand-curated in `manifest.json`.
String-literal syntax currently has parser-only evidence because the legacy
tokenizer accepts quoted text but does not preserve a literal token kind for
typechecking.

Run the corpus without the generated smoke suite with:

```sh
python3 src/HolSmt/tools/run_conformance_suite.py \
  --no-default-suite \
  --corpus-dir src/HolSmt/tools/conformance-corpus/v1 \
  --out src/HolSmt/tools/conformance-out/core-uf-arithmetic-v1
```
